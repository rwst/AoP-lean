# AoP-lean
Lean4 formalizations of documents of the Assumptions of Physics project

At the moment there are only formalizations of the AoP [briefs](https://assumptionsofphysics.org/resources/briefs) in the [briefs directory](briefs/), where the main statements are verified but remarks or side arguments are not. This is being done currently, as well as [comparator](https://github.com/leanprover/comparator) setups for the main statements of each brief.

The [ForMathlib](ForMathlib/) and [ForPhyslib](ForPhyslib/) directories contain formalizations of theorems missing in [Mathlib](https://github.com/leanprover-community/mathlib4) and [physlib](https://github.com/leanprover-community/physlib), respectively, that were needed by this project.
